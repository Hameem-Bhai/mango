# Mr. Mango BD — Official Vape E-Commerce Platform

The complete full-stack e-commerce web platform for **Mr. Mango BD**, featuring 100% authentic disposables, refillable pod kits, imported e-liquids, cartridges, live search, WhatsApp ordering, bKash/Nagad checkout, dark mode, and an administrative management dashboard.

---

## 🚀 Quick Start on a New PC

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher ([Download](https://nodejs.org/))
- **Git**: Installed and configured

### 2. Clone Repository
```bash
git clone <YOUR_REPO_URL>
cd Mr.Mango.com
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start Development Servers
Run frontend and backend simultaneously:
```bash
npm run dev
```
Or run them in separate terminals:
```bash
# Terminal 1 (Frontend Vite dev server):
npm run dev:client

# Terminal 2 (Backend Express API):
npm run dev:server
```

- **Frontend**: `http://localhost:5173`
- **Backend API**: `http://localhost:5000`

### 5. Build for Production
```bash
npm run build
```
